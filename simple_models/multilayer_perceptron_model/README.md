# Multi-layer Perceptron (MLP) Implementation

---

* This repo contains MLP architecture implementation using pytorch framework on the housing dataset.
* Ablation studies have been conducted on the dataset using different architecture
* Results folder contains the saved model and the plots
* Note: modelv5 was overwritten while training, so the saved v5 is actually the last trained model in the experiment_log csv file

---

* config script contains all the hyper-parameters by changing their values the model can be modified and performance can be evaluated
